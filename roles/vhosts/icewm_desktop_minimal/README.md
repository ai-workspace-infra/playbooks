# IceWM Minimal Desktop

An intentionally small, independent desktop role for Debian-family hosts. It
uses `icewm-session` and provides only the desktop plumbing, terminal, file
manager, Chromium, and optional XRDP remote access needed for setup and CLI
debugging.

It does not install XFCE, office software, Wine, video players, media suites,
AI runtimes, or monitoring agents.
