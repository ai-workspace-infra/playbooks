# Guance Cloud Dashboards Role Storage

本目录存储与 Ansible 角色 `roles/grafana-dashboard` 对齐的观测云（Guance Cloud）标准仪表板定义文件。

完整文档与全局规范参见顶级目录：
- [`dashboards/guance-cloud/README.md`](../../dashboards/guance-cloud/README.md)

### 包含的仪表板定义：
1. `caddy-dashboard.json`: Caddy 网关监控（25 面板）
2. `postgres-unified-overview.json`: PostgreSQL 统一监控概览（14 面板）
3. `starsl-k8s-dashboard.json`: K8S 集群监控 StarsL.cn（33 面板）
